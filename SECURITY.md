# Security Policy

## Supported Versions

We currently support the following versions of Go-WAF:

| Version | Supported          |
| ------- | ------------------ |
| v1.x    | :white_check_mark: |
| < v1.0  | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within Go-WAF, please send an e-mail to security@samaasi.com. All security vulnerabilities will be promptly addressed.

Please include the following in your report:
- Type of issue (e.g., buffer overflow, bypass, etc.)
- The location of the affected code
- A proof-of-concept (PoC) or steps to reproduce
- Potential impact

We will acknowledge your email within 48 hours and provide a timeline for a fix.
